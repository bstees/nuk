# nuk

`nuk` is a clean-room component system built around semantic HTML, native browser behavior,
accessible defaults, and small typed adapters. Its default custom-element namespace is `nuk-`.
Applications can choose a different prefix at registration time without rebuilding the library.

## What to review

- Use the toolbar to switch between system, light, and dark color modes.
- Change the story container between 20, 42, and 72 rem to inspect reflow without viewport
  breakpoints.
- Open the accessibility panel on every component story; violations fail automated Storybook checks.
- Try the examples with a keyboard. Native elements are preferred wherever they can provide the
  behavior.
